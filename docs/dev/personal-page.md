# 個人ページの検証・制限

## 対象

- /me/connections：Google未連携、今後の認可工程と開発予定、テスト表示への入口。
- /me：ログイン不要で、今日から31日間の固定相対テスト予定を表示。
- 月間・詳細・候補は同じ入力から生成。終日予定は件数によらず日別6時間、通常予定と加算し活動時間上限。時間別は時刻指定のみ。
- DB・Google・LINEへ保存／接続／送信しない。OAuth受付を作らない。案内文・除外日は再読込で戻る。

## 確認手順

1. node --test test/personal.test.js test/line-webhook.test.js test/line-cards.test.js
2. npm run lint
3. npx base44 build（公開はしない）
4. npx base44 dev（ローカルバックエンド。--remoteは使わない）
5. /me/connectionsで今後実装予定の説明を確認。
6. テストデータで試す→31日表示→日付選択→詳細・終日欄を確認。
7. りすけ入力→最大3候補→複数選択→文面編集・コピー。
8. 日付を除外して候補が更新されること、候補選択が前の結果から残らないこと、再読込で除外が戻ることを確認。
9. 画面幅390px・1280px、キーボード操作、匿名で固定テスト予定のみ返ることを確認。

## 今後の開発予定

Google利用者別認可、トークン保管、読み取り範囲、全ページ取得、解除・期限切れ、完成版保存、共有画像、LINEとの接続。テスト表示でこれらの完了を主張しない。

## コミットメッセージ草案

[機能] Google連携前に予定表示と候補選出を検証できる個人ページを追加


## 今回の結果

26件のテスト、コード検査、ローカルHTTP（GET 200/no-store、入力の接続先切替不可、POST 405）、ブラウザーの候補選択・コピー・除外・再読込・日別終日欄・狭い幅を確認。詳細はdocs/spec/checks.md末尾。
既存のCSRF未設定警告は残る。今回の固定データGETに業務上の副作用はない。実データ・書込接続前に本人認証とCSRF対策を追加・検証する。

PC版は参考HTMLのデザインを踏襲。日付選択だけでは詳細を開かず、「選択日のスケジュール」で開く。候補はショートカット入力で表示する。日別・候補の計算、テスト表示のHTTP境界に変更なし。

## 2026-10-18 UI更新（最新の表示仕様）
提供された「りすけ（1人・PC版）」「りすけ（2人・PC版）」「りすけ（スマホ版）」のHTMLを見た目の基準にする。カレンダー・日別詳細を先頭、候補探索ボタンをその下に置く。1人版の詳細は常時表示。PCは05:00〜24:00の表示枠、活動時間外は明記し計算には使わない。スマホはモード切替・曜日行・横スワイプ候補・選択数の固定バー・連絡文ダイアログを使う。共有は利用者が押したときだけOSの共有画面を開き、非対応時はコピーする。
画像内は月日数字・多忙度の色・候補の★だけ。上下の見出し、凡例、期間、更新時刻、版番号、「候補」の文字は描かない。版と生成時刻は共有DTOと保存ファイル名で引き続き管理する。画像保存はPNGの端末ダウンロードまで。
候補日以外に相手の時間帯を出さない。HTML内の固定日付・予定名・計算式は実装指示と扱わず、既存の認可境界・合意済み選出処理を維持する。

### 月表示とヘッダーの調整
月バッジは今日と各月1日のセルだけに表示し、セル幅に追従する文字サイズを使う。ヘッダーはブランド・モード切替・連携リンクとテスト表示の1行にまとめ、カレンダーを最初に見せる。
