# Google Calendar読込

/accountでログイン→接続状態を確認→Googleの予定を読み込む。GOOGLE_CALENDAR_CONNECTOR_IDにBase44の利用者別Connector IDが必要。Google OAuthクライアントIDを代用しない。ブラウザへの認可トークン・生イベントの返却なし。

匿名/meと/me/pairは固定テスト専用。/accountはメインカレンダーの31日分を都度取得し、その場で演算。DB保存・相手の認可利用・LINE共有・公開は行わない。取消・重複を整理し、accepted参加または本人主催のみ評価。既存ルールのため未回答・仮承諾・辞退・透明・勤務場所は多忙扱いしない。別カレンダーは未対象。

確認順序：固定API応答テスト→lint→Base44 build→匿名RPC401→実ログイン→接続→読込。Base44プラットフォームヘッダーが必要なため、ローカル認証・利用者別接続は実機確認が必要。認証できない場合にローカルへサービス資格情報を直書きしない。

ログはrequest_id、段階、件数、所要時間、分類済みコードのみ。401認可、403 API有効化/権限、429待機、通信失敗、Connector設定を切り分ける。Base44404はID誤りと未接続を断定できない。全ページ完了前の結果は使用しない。実接続は未検証。
