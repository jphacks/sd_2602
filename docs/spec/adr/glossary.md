# 用語集

更新日：2026-10-18。

| 用語 | 意味 | 正本 |
| --- | --- | --- |
| 芝 | 日別多忙度を色で示すヒートマップ | [外部設計](../external.md) |
| 多忙度 | 活動時間に対する多忙分数の割合。終日合成等は判断待ち | [契約](../contracts.md) |
| 活動時間 | 集計対象となる本人の時間帯。現計算は1区間の仮実装 | [契約](../contracts.md) |
| 候補日 | 本人の余裕から提案する日付。全員の空き・時刻一致・確定を意味しない | [外部設計](../external.md) |
| DTO／表示用データ | 相手に必要な項目だけをまとめた受渡しデータ。DB全体をそのまま返さない | [契約](../contracts.md) |
| UIのみ | 準備中・表示デモ。業務キュー・保存・実APIを起動しない | [機能一覧](../features.md) |
| モック | 固定入力や模擬接続。実接続の証拠と区別する | [機能一覧](../features.md) |
| queued | 耐久受付済みで実行開始前。自動実行の仕組みそのものではない | [ログ](../logs.md) |
| キュー | 待機依頼を保持する仕組み。採用基盤は未決 | [内部設計](../internal.md) |
| ワーカー／実行担当 | 待機依頼の実行権を取得し、計算・保存・送信を進める役割 | [内部設計](../internal.md) |
| run／OperationRun | 有効な操作全体の実行記録。DB標準idとrun_idは別 | [ログ](../logs.md) |
| stage | 受付・取得・計算等の段階。実行状態とは別 | [ログ](../logs.md) |
| 版 | 入力・計算・結果・許可を識別する値。UUIDの大小で順序を推測しない | [ログ](../logs.md) |
| グループ共有許可 | 本人×グループの許可。本人・Google連携とは独立 | [権限](../access.md) |
| 共有スナップショット | LINE依頼時に保存済み結果と画像の同じ元版を固定した公開情報。後続更新で差し替えない | [LINE](../line.md) |
| sent／unknown | LINE API受理確認／受理有無不明。端末表示・既読とは別 | [ログ](../logs.md) |
| superseded | 古い実行として最新結果に採用しない終了状態 | [ログ](../logs.md) |
| 共有画像 | カレンダー更新後にWebUIの共有用部分を画像化して保存したもの。保存時点でグループ公開とはしない | [LINE](../line.md) |
| 候補カード一式 | 保存済み同一版の画像・候補・説明・提案ボタンと、同じ版の共有ページへ進むもっと見る | [LINE](../line.md) |
| 判断待ち | ユーザーの選択前。実装や合格判定で勝手に補完しない | [判断一覧](../decisions.md) |
