# Manager：カードとキーワード応答のセット管理

更新：2026-10-17。

## 決定した目的
- 対象はLINE Official Account Managerの「メッセージアイテム」で作成するカードタイプメッセージ。
- 利用者はモックカードを作成済み。自作BotのFlexカードではない。
- 完成形は「カード一式＋キーワード応答ルール」をセットで自動作成・削除・再登録する。
- 削除は送信済みメッセージの取消ではない。Manager内の登録設定・アイテムが対象。
- 利用者は無効化だけでなく、旧応答を削除して同じキーワードを再利用する方針を選択。
- 新しいカードを先に用意→対象の旧応答を削除→同じキーワードで新応答を登録→確認後に不要な旧カードを削除する案。
- 管理名で自動化対象を限定する。削除から登録の間に応答不能期間が発生し得る。
- 作成・削除の実証は未了。公開APIでManagerのこの設定を管理する方法は今回の調査では確認できていない。ブラウザー操作による検証を計画。

## 方式の区別
Manager組込みのキーワード応答と、Webhook Botのキーワード判定は別機能。
Manager方式を試す際は該当応答を有効にする。Bot検証時の「応答メッセージOFF」を機械的に適用しない。
個別トークでまず確認し、グループでも同じように動くとは検証なしに保証しない。
